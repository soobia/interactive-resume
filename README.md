# Interactive Resume

A Google-style interactive resume built with HTML and JavaScript. Designed to 
surprise and delight recruiters instead of sending a standard PDF.

When you open it, it auto-types a name into the search bar and presents 
search results -- complete with a knowledge panel, People Also Ask section, 
and sitelinks -- all pointing to real experience and work.

Live site: https://soobia.github.io/interactive-resume

---

## Features

- Realistic Google search UI with typing animation
- Interactive search bar -- type a name and hit Enter to see results
- Searches for your name show the resume results
- Searches for anything else show a "no results" page with a "Did you mean" redirect
- Knowledge panel with contact info and skills
- People Also Ask section with expandable answers
- Sitelinks linking to different resume versions (coming soon)
- Role-specific resume versions via URL parameter (coming soon)

---

## Built with

- Vanilla HTML, CSS, JavaScript
- No frameworks, no dependencies
- Runs entirely in the browser
